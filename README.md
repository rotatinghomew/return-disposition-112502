# 退货原因的可比归因与仓配处置

这是一个保存合成业务资料的 Python 项目，并在资料加载层之上提供三类能力：

- **可比归因**：自由文本 / 标准原因 / 质检结论三层证据分层归因；原因字典与
  商品规格按版本解释，历史记录按当时口径，跨版本记录显式标记不可直接比较；
  在渠道 × 批次的可比队列内给出原因分布、复购影响、无法归因比例，
  跨期比较用结构校正区分订单结构效应与率效应。
- **仓配处置**：按证据三态给出再售 / 翻新 / 隔离 / 补货建议，逐条记录
  库位容量、质检能力、已承诺换货、采购到货日期等约束；已执行的退款、
  处置和已发出的换货不可静默改写，只有未执行的处置会被重计划。
- **追溯回查**：从任一处置建议回查订单事实、原因证据、商品版本与容量冲突，
  并按原因族比较后续批次是否支持原先的质量判断。

资料位于 data/，所有记录都带有合成资料标记。不同文件之间通过稳定标识和
时间字段关联，缺失、部分质量和待处理状态都是资料含义的一部分，不能在读取时
静默填充。字段说明见 docs/data-dictionary.md，能力设计见 docs/design.md。

运行基线测试：python3 -m unittest discover -s tests -v
检查 Python 文件：python3 -m compileall src tests
生成分析报告：PYTHONPATH=src python3 -m return_disposition data
